# Playable complete-character frame bank

Canonical runtime native art and registrations are in `assets/mac-combat-frames/`. The standalone study remains at `review-mac-combat-frames/` as accepted review history. Each runtime registration hashes its exact native PNGs, measures full-body crops and uses one scale per sheet. No native pixels are rewritten during registration or packaging.

The bank contains 126 registered drawings across twelve PNGs; selected gait/action sequences reuse held cels. Mac's accepted walk uses four keys. Jump load, takeoff, chamber, extension, contact, recoil, descent and landing follow actual simulation phases/events. Enemy hit tells remain matched to the original delayed contact times. Foot anchors for passing and airborne poses are manual visual waist/hip projections where the lowest opaque pixel belongs to a swinging shoe or weapon. These are anatomy judgments, not alpha-based anatomy detection.

Native technical checks cannot establish owner liking, device FPS or physical-controller acceptance. The game remains a private draft for playtesting. Original artwork/audio and rejected rig assets remain recoverable history, while the game entry launches only complete-character playback.
