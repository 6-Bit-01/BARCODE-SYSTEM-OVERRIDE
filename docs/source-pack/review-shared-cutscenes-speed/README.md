# Scripted visual example — shared reading and speed effects

These files render production Canvas owners with bundled source art and
scripted state. They are local review evidence, not a Makko recording,
physical-controller session, measured frame pacing or human acceptance.

- `Opening-01.webp`, `Bridge-01.webp`, `Ending-04.webp`: the same reading toolbar
  and chapter-specific unchanged artwork/dialogue.
- `Opening-Pause.webp`: the common reading Pause/Resume presentation.
- `Cache-Road-Mirror-Preview.mp4`: 12 seconds of scripted ordinary driving,
  Turbo, pass/impact presentation with the real painter. Compressed to 24 FPS
  for sharing; this does not measure gameplay FPS or illustrate a new speed.
- Road stills: ordinary, Turbo and a pass, with fixed HUD/rearview and peripheral
  wind/pressure paint. The center timing space stays readable.
- Scene JSON: native text/protected-art checks and motion accessibility samples.
  Opening native review also checks all eight current-page transcripts.

The complete suites, exact final head and hosted Chromium results are recorded
in the PR/export receipt. Makko comfort, audible pause/resume, physical input
and frame pacing remain owner acceptance. Regenerate with
`tools/render-cache-road-mirror.cjs`, the two Cache scene renderers and
`tools/render-intro.cjs --comic-only <directory>`. No gameplay tuning is implied.
