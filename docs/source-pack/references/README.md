# Historical Asset References

`v4-audit/` preserves selected July 15, 2026 v4 audit material verbatim. These are historical inventories and contact sheets, not current build instructions or a new remote-asset verification. Their dates, hashes, gaps and policy notes are preserved as evidence of what that older pack recorded. Current v5 instructions take precedence over any old recommendation in the registry.

- `v4-audit/visuals/LEVEL_1_ASSET_CONTACT_SHEET.png`: approved title, environment, Jammer, lore object and representative flying-traffic frames.
- `v4-audit/visuals/LOCKED_INTRO_CONTACT_SHEET.png`: nine unique intro images represented by the earlier eleven-entry runtime map. Verify continuity; do not redesign them.
- `v4-audit/visuals/CURRENT_SPRITES_PARTIAL_CONTACT_SHEET.png`: partial earlier Makko sprite exports demonstrating transparency, anchors and animation scale.
- `v4-audit/assets/ASSET_REGISTRY.json`: original source URLs, dimensions, historical download hashes and approval observations.
- `v4-audit/references/AUDITED_*_MANIFEST.json`: original metadata mirrors referenced by the registry. Its `pathBase: pack-root` means the `v4-audit/` folder for these preserved files.

Use `repository-snapshot/sprites-manifest.json`, `audio-manifest.json` and the actual source when assessing the current exported revision. Do not overwrite them with these older mirrors. No source ZIP, old PR prompt or speculative asset order is nested here.
