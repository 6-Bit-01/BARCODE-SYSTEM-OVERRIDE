# Cache Road individual roadside places

These ten transparent places replace the rejected long market, depot and
frontage strips. Every image is one separate parcel or building with oblique
depth painted into its own roof, walls and footprint. It is placed as a whole
object at a deterministic road-world coordinate and grows uniformly as it
approaches the car. The right side mirrors the diagonal art; there are no
horizontal slices or per-column distortions.

| Runtime WebP / source PNG stem | Individual place | Visual role |
| --- | --- | --- |
| `corner-market` | Occupied corner shop | Small commercial |
| `row-house` | House and garden | Residential |
| `parking-lot` | Open fenced car park | Large ground break |
| `pocket-park` | Path, benches and trees | Green open break |
| `repair-garage` | Single workshop | Low service building |
| `apartment` | Narrow four-story studio/apartment | Tall landmark |

| `community-garden` | Raised beds and greenhouse | Green open break |
| `construction-yard` | Fenced site and scaffold | Industrial break |

Generated with the built-in image tool on September 25, 2026 using separate
prompts for each place. Shared prompt: a single isolated transparent 2.5D
roadside game prop; weathered navy-charcoal rainy night material, controlled
cyan/magenta and amber lighting; a large near corner at lower left with its
side/footprint receding toward upper right. No joined facades, panoramic road,
traffic, sky, people or readable words. Each subject and its distinctive
footprint was specified separately. Original generated outputs are retained
by the image workflow; `sources/` contains transparent PNG reductions and
the WebPs are optimized runtime art. Dimensions and alpha are preserved at
the same aspect ratio. No source contains another parcel to be sliced out.
