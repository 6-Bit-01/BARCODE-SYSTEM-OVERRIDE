# Cache Back mirror expression sheet

`cache-back-mirror-expressions.webp` is a 3 × 2 atlas of six 512 × 512 cells.
Reading order: calm, focused, Turbo/Zone, close pass, collision, low signal.
The source PNG is kept under `sources/`.

It was generated from the owner's Cache Back model
`openart-image_sUa578AT_1765587750737_raw(1).png`. The prompt specified a
consistent partial face entering from the left edge, yellow cap and side
protrusions, clear black glasses, one visible brown eye looking straight ahead through the windshield in five cells, and a brief rightward glance into
the mirror on collision (bottom center). It keeps the upper angular mask,
dark navy negative space, and six eye/brow reactions. It explicitly excluded
a frame, road, text and separate card. The
model reference remains in the owner's files rather than being copied here.

The runtime crops the eye/upper-mask band from each cell and blends it inside
the mirror glass. The road reflection is decorative and never communicates
actual traffic danger.
